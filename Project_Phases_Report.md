# FitBuddy - AI Fitness Plan Generator
## Project Documentation & Requirement Analysis (Phases 1 to 8)

### Phase 1: Brainstorming & Ideation
- **Project Name:** FitBuddy - AI Fitness Plan Generator
- **Problem Statement:** Accessing personalized workout routines and nutrition guidance often requires expensive personal trainers or complex software.
- **Solution Idea:** An easy-to-use AI-driven Web Application built using Python and Streamlit that collects basic user details (Age, Weight, Fitness Goals) and automatically generates custom workout routines.

### Phase 2: Requirement Analysis
- **Software & Languages:** Python (v3.8+), Streamlit Web Framework, Git, VS Code editor.
- **Functional Requirements:** Interactive UI for inputting Age, Weight, and Fitness Goal; Instant generation of daily workout plans.

### Phase 3: Project Design
- **System Architecture:** User Interface (Streamlit) -> Input Processing (Python Backend) -> AI Recommendation Engine -> Customized Plan Output.

### Phase 4: Project Planning
- **Timeline:** Ideation & Analysis -> Architecture Design -> Development (`app.py`) -> Testing -> Final Submission via GitHub & Drive.

### Phase 5: Project Development
- Core application code written in Python using Streamlit in `app.py`.

### Phase 6: Project Testing
- **Test Case:** Valid user inputs verified for workout generation. Status: PASSED.
